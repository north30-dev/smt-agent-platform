# SMT 设备常见故障与处理手册

## 1. 贴片机（MOUNTER）常见故障

### 1.1 吸嘴堵塞
- **现象**：抛料率升高、拾取失败率增加
- **原因**：锡膏残留、异物进入吸嘴通道
- **处理**：
  1. 停机并执行安全锁定（LOTO）
  2. 拆卸吸嘴，使用专用清洁工具清除残留物
  3. 检查吸嘴真空度，确认负压值在 -60kPa 至 -80kPa 范围
  4. 清洁后执行吸嘴校准程序

### 1.2 温度异常
- **现象**：设备温度报警、振动增大
- **原因**：轴承磨损、润滑不足、冷却系统效率下降
- **处理**：
  1. 立即停机，防止二次损伤
  2. 检查运动轴承润滑状态
  3. 检查冷却水循环系统
  4. 使用激光对位仪校准运动轴

### 1.3 贴装精度偏移
- **现象**：元件贴装位置偏差、AOI 检测不良率上升
- **原因**：视觉系统漂移、运动轴磨损
- **处理**：
  1. 执行视觉系统重新标定
  2. 检查 X/Y/Z 轴运动精度
  3. 校准吸嘴高度和压力参数

## 2. 回流焊（REFLOW）常见故障

### 2.1 温度曲线异常
- **现象**：焊接质量下降、冷焊或过焊
- **原因**：加热区温控失灵、热电偶故障
- **处理**：
  1. 检查各加热区温度传感器
  2. 校准温控器参数
  3. 使用测温板验证温度曲线

### 2.2 传送带速度异常
- **现象**：PCB 板传输不稳、卡板
- **原因**：传送带磨损、电机驱动异常
- **处理**：
  1. 检查传送带张力和磨损情况
  2. 清洁传送轨道
  3. 校准传送速度参数

## 3. AOI 检测仪常见故障

### 3.1 误判率升高
- **现象**：假缺陷报警增多、漏检率上升
- **原因**：光源老化、镜头污染、算法参数漂移
- **处理**：
  1. 清洁镜头和光源
  2. 检查光源亮度是否在标准范围
  3. 重新训练检测算法参数
  4. 使用标准样板验证检测精度

## 4. SPI 检测仪常见故障

### 4.1 锡膏厚度测量偏差
- **现象**：测量值与实际不符、误报增多
- **原因**：激光传感器校准偏移、镜头污染
- **处理**：
  1. 使用标准厚度板重新校准
  2. 清洁激光传感器镜头
  3. 检查环境温湿度是否影响测量

## 5. 安全操作规范

1. 所有维修操作前必须执行 LOTO（上锁挂牌）
2. 佩戴防静电手环和防护眼镜
3. 禁止在设备运行时进行清洁或调整
4. 维修完成后必须执行设备自检程序
5. 记录所有维修更换的部件和参数调整
