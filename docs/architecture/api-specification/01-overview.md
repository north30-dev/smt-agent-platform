**版本**: v1.1 | **日期**: 2026-07-11 | **状态**: Phase 3-4

## 一、文档概述

### 1.1 目标

本文档定义了SMT智能运维平台所有服务的API规范，包括：

- Java后端服务API（网关 + 设备管理）
- Python智能体层API（6个Agent）
- 大模型服务API（LLM Service）
- 中间件服务接口

### 1.2 API分层架构

```
┌─────────────────────────────────────────────────────────┐
│  交互层（Phase 4）                                       │
│  - React前端应用                                         │
│  - 用户界面与可视化                                       │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│  智能体层（Python）                                       │
│  - Scheduler (8001)    → 生产调度                        │
│  - Maintenance (8002)  → 设备运维                        │
│  - Quality (8003)      → 质量分析                        │
│  - Knowledge (8004)    → 知识检索                        │
│  - Scheduler (8005)    → 编排协同                        │
│  - Execution (8006)    → 执行智能体                      │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│  服务层（Java）                                          │
│  - Gateway (8080)        → API网关路由                   │
│  - Device Service (8081) → 设备台账管理                   │
│  - Spring Boot + MyBatis-Plus                           │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│  数据层                                                 │
│  - PostgreSQL (5432)   → 关系型数据                      │
│  - Redis (6380)        → 缓存                            │
│  - InfluxDB (8086)     → 时序数据                        │
│  - Milvus (19530)      → 向量检索                        │
│  - LLM Service (1234)  → 大模型推理                      │
└─────────────────────────────────────────────────────────┘
```
